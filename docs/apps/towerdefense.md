# Tower Defense

Tower Defense is a solo game played through the public Game Hub page. The desktop window opens the game and offers to install Game Hub when needed. Players sign in with their Apps Hub profile; completed runs appear in their Game Hub history and rankings.

## Defend and upgrade

The tower fights automatically during each wave. Between waves, spend coins on weapons, repairs, tower upgrades and battlefield defences. Equip up to three weapons. Tap the heading of a mounted weapon to unmount it when another weapon remains equipped. Upgrade icons show their names in tooltips.

The shop keeps owned and currently affordable items visible. Expand a category heading to see its other items. Tap an enemy or boss in the next-wave preview to read its description. The HUD contains the button to start the next wave.

On phones the arena fills the portrait space with the tower in the centre. Landscape screens show a square arena. The simulation is the same in either view.

## Permanent progress and saves

Points earned from runs buy permanent upgrades for later games. The best wave is remembered. Use Exit to open Game Hub's save and exit prompt; a saved solo run can be continued later.

## Fast play

With the Premium build present and the owner's Fast play switch enabled, players can choose speeds from normal to ×10 and start waves automatically. Slower devices may run below the selected speed to keep the page responsive. Auto waves can stop at a selected wave up to the existing record; the shop then opens and speed returns to normal for that run.

The controls appear during waves. Press the save icon to keep the current speed, Auto waves choice and stopping wave for new games in this browser. Changing a running game does not replace that saved setup until Save is pressed again.

The owner's switch is in the desktop launcher. Without Premium it stays visible and opens the Premium dialog; public players simply have the ordinary game without Fast play controls.
