# Chat

Chat 1.4.4 requires an Apps Hub sign-in before the desktop window opens. Conversations use that profile rather than the Linux desktop account. The same profile can open the public page when the administrator enables it.

Use the conversation list or search for another profile, open a conversation and send a message. Favourites are shared with Apps Hub. Sign out through the shared profile menu when changing accounts; desktop and public profile identities are separate from Linux login.
