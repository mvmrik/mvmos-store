# Calendar

Calendar 1.4.0 signs in through Apps Hub before opening its desktop window. The same profile's events are available on its public page when the administrator enables it.

Choose month, week or day view, add timed or all-day events and mark them done. Repeating events can be daily, weekly or monthly until an end date; changes can apply only to one occurrence, that and future occurrences, or all upcoming ones. The interface, month and weekday names support all nine mvmOS languages. Dates and time controls use the shared regional picker.

Reminder notifications require the mvmOS scheduler to be enabled in Cron Manager. Calendar's App API is off by default and can be enabled in Apps Hub → Settings → App APIs for intended integrations.
