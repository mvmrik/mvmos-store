# Hydration

Hydration keeps each completed day’s water goal, offers drink colours and custom emoji icons, and can end the day after midnight.

## Other sources and reward destinations

Hydration 1.4.0 can include water that other apps sent to Health. Enable Health's App API in Apps Hub → Settings → App APIs, where it is off by default, then select the option to read other sources in Hydration's Settings. The current day's source rows identify each contributing app and amount; the ring and current progress include that water and exclude Hydration's own contribution from the imported total.

The optional Premium Budget reward accepts several destination categories. Each receives the full configured reward, optionally funded by a source category for each destination. Existing single-category settings are migrated without losing the selection. Budget must be installed with its App API enabled; that switch is off by default. Without the Premium module, the desktop setting opens the Premium prompt and the public reward feature is absent.
